1. Copy the complete vehicle_rental folder into C:\xampp\htdocs\
2. If an older vehicle_rental folder exists, replace it with this folder.
3. Start Apache and MySQL in XAMPP.
4. Make sure the vehicle_rental database is imported.
5. Keep the 14 vehicle photos inside vehicle_rental\images\ with the filenames already used in the database.
6. Keep qr_code.png in the project root.
7. Open: http://localhost/vehicle_rental/
